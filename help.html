Getting started

Open index.html on an HTTPS host such as GitHub Pages. MirOS plays its startup sequence, then opens first-time setup if this browser has not completed setup. Setup choices are stored locally in this browser.

  • Complete the setup pages and choose a local profile name.
  • Choose Wallpaper 1 or Wallpaper 2, or select a built-in gradient.
  • Finish setup. MirOS returns through the boot screen before showing the lock screen.

Desktop shortcuts

Use the desktop context menu to create a shortcut for an installed app. Drag apps from Start or MirStore onto the desktop grid. Drag an existing shortcut to reposition it. A single click selects; a double-click opens.

Removing a desktop shortcut does not uninstall the app. Uninstall apps separately in MirStore.

Start Menu

Open Start from the taskbar. Search and All Apps show installed apps only. Apps you have not installed remain in MirStore. Pin frequently used apps and use the context menu to pin apps to the taskbar or create desktop shortcuts.

Taskbar

Pin installed apps to the taskbar. A green underline marks an app that is open or minimized. Click a minimized app's taskbar icon to restore it. Minimize hides a window without closing it; Close ends that app window.

MirStore

MirStore contains MirOS apps and optional website apps. MirCodeStudio is included by default. Select Install to add an optional website app to the local installed list; it then appears in Start. Some sites prevent embedding, so MirOS may offer to open them in a browser tab.

Wallpapers

Keep wallpaper.png and wallpaper2.png in the same folder as the MirOS HTML files. Wallpaper 1 (wallpaper.png) is the default. Wallpaper Studio and first-time setup show visual previews of both assets. The images are user-supplied assets and are not included in the project ZIP.

If a preview is missing, check the filename spelling and letter case, and make sure the image is uploaded beside home.html.

Lock screen

The lock screen shows the selected wallpaper, time and date. Tap it to reveal the sign-in panel. Choose a PIN, pattern, password, tap-to-unlock fingerprint-style option, or no credential in Settings. The tap-to-unlock option is a convenience gesture, not fingerprint verification.

Settings

Settings contains categories for appearance, desktop, display, sound, applications, profile and lock screen, network, storage, notifications, accessibility, privacy and system recovery. Use the search field to find a setting. Open actions should lead to their related panel or diagnostic.

Files and storage

MirOS virtual files are stored in browser-managed IndexedDB. Import files only when you select them. Export important data regularly using Backup & Restore. MirOS cannot silently access all files on your Windows device.

Offline support

The service worker caches the MirOS shell and optional wallpaper assets when they are available. Local tools may continue to work offline. External websites, online maps, weather, AI services and live integrations require a connection and may not work offline.

Mobile and tablet use

MirOS uses responsive layouts and touch-friendly controls. On narrow screens, setup becomes a single column, desktop shortcuts reflow into a grid, windows fill the available screen and taskbar controls compress. Rotate your device if a wide app needs more space.

Troubleshooting

  • Blank or stale screen: refresh the page. If the old interface remains, close the MirOS tab and reopen it so the new service worker can activate.
  • Wallpaper missing: verify both PNG files are uploaded beside the project files.
  • Website app does not load inside MirOS: use its Open in browser option; the website may block iframe embedding.
  • Settings do not save: check browser storage availability and avoid private browsing modes that clear site data.
  • Offline app unavailable: connect once while online so the shell and supported assets can be cached.

Privacy and browser limitations

MirOS stores its own profile, settings, pins and virtual files in this browser. External websites have their own privacy policies and storage. Browser permissions control access to files, camera, microphone, location and notifications.

MirOS is a browser-based workspace, not a native Windows replacement. A web page cannot guarantee closing the entire Edge window, powering off Windows, or accessing native PC applications. Shutdown ends the MirOS session and displays its powered-off state; the browser may keep the tab open.

Do not place API keys, passwords, private tokens or developer credentials in public HTML, JavaScript, README files or GitHub Pages repositories.
